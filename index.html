AI 摘要 · 593 字

今天整份简报串起来看，主线很清楚：模型与 agent 的能力还在加速，可安全约束、算力供给和商业定价，都还没完全跟上。安全侧，Guidelight 的评估几乎给不出「公开且可执行」的失控模型遏制样板，OpenAI 相对靠前，Anthropic、Meta 等公开度更低；社区随之把「Kill Switch」从口号推向流程与问责。能力侧却很热闹——Inherent 由 DeepMind 背景团队创办，27B 的 Faraday 在科研论文复现任务上挑战更大参数模型，说明「小模型 + 强任务设计」仍能打穿榜单叙事。价格战同步升温：OpenAI 下调 GPT-5.6 Sol API 单价，开发者调用更便宜，订阅档未动，利润压力转嫁到用量增长；另一头 Nvidia AI 服务器报价上调逾一成，HBM 与供应链把 2027 年扩产预期压得更紧，超大规模厂商的资本开支故事开始被市场重新计价。Anthropic 引入前 Google TPU 负责人并推进芯片合作，是在补算力自主的短板；开源社区则以 DeepSeek Harness 等项目，把 agent 编排、工具调用和长期任务跑通，变成可复用工程件。版图之外，北极航线试运营、Zagreb 接入 Uber 自动驾驶、Jackson Hole 前的利率沟通，提醒 AI 叙事仍嵌在物流、出行与宏观利率里。若只留三句话：安全预案要与能力同速；便宜推理会重塑谁能做产品；算力与开源脚手架，将决定下一轮真正能落地的 agent。
